# Personal Introduction Page

## Description
This project is a simple personal introduction webpage developed using HTML5 and CSS3.

## Features
- Personal Profile
- Profile Image
- About Me
- Skills
- Hobbies
- Contact Information

## Technologies Used
- HTML5
- CSS3

## Project Structure

Personal-Introduction/
│── index.html
│── style.css
│── profile.jpg

## How to Run
1. Download or clone the repository.
2. Open the Personal-Introduction folder.
3. Double-click index.html or open it using Live Server in VS Code.

## Outcome
This project helped me learn:
- HTML page structure
- CSS styling
- Images
- Lists
- Basic webpage layout
